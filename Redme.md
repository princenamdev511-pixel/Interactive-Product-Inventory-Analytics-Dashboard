# Interactive Product Inventory & Analytics Dashboard

This is a simple JavaScript project to manage products and analyze inventory.

### Features

* Add products and prices.
* Categorize products by price.
* Calculate total inventory value.
* Filter affordable products.
* Display a formatted product report.

### Technologies Used

* JavaScript

### How to Run

1. Open the project in VS Code.
2. Run the JavaScript file in a browser environment that supports `prompt()`.
3. Check the output in the console.
